# 小雪圖像來源

assets/xiaoxue-atlas.png：1536×1024 RGBA、三欄兩列六格圖集。

本次依使用者要求生成：可愛灰色雪納瑞、蓬鬆眉毛與鬍鬚、青色項圈、青／粉霓虹輪廓光、3D 渲染材質、透明背景、同一角色六種姿態。依序為歡迎、解說、工作、等待、擔心、成功，沒有文字或商標。

mascot.py 以 Pillow 裁切各格並縮放，按階段切換，可關閉浮動。這是預渲染視覺素材，不含 .blend／.glb 網格、骨架、材質工程檔或可旋轉視角。

交付包含生成的原始圖集，沒有另行下載第三方角色圖像。Linux 畫面測試使用 Noto 字型和 Xvfb，僅為測試環境、不隨產品打包；Windows 使用 Microsoft JhengHei UI／Consolas 系統字型。
